## 分數解讀
### 事件重要分數
- 90～100：非常重要
- 70～89：高重要
- 40～69：中等
- 0～39：低重要

這不是上漲機率，也不是買賣分數。

### 資料可信度
- 90%以上：官方資料或高度可信
- 70～89%：可信度中高
- 50～69%：建議搭配其他來源
- 50%以下：需再查證

### 對我的影響
- 直接影響目前持股：最高
- 影響整體市場：中等
- 非目前持股：最低
