# Jay Invest V6.2 — Generic Balance Strategy

## 本版重點

原本的「正2平衡策略」已改成：

> 平衡策略

不再限制只能用在正2 ETF。

## 使用方式

開啟平衡策略後，可以從目前持股下拉選單中選擇一檔標的，例如：

- 00631L
- 0050
- 009816
- 台積電
- 任何目前實際持有的股票或 ETF

系統會只使用：

`指定持股市值 + 可投資現金`

計算目前比例與建議調節金額。

## 條件顯示

平衡策略關閉時：
- 不顯示持股選擇
- 不顯示目標比例
- 不顯示容忍區間
- 首頁不顯示平衡資訊

平衡策略開啟時：
- 顯示目前持股下拉選單
- 可選擇要套用平衡的標的
- 顯示指定持股／可投資現金比例
- 超出容忍區間才顯示建議調節金額

若選擇的標的已經沒有持股：
> 未持有指定標的，策略不啟動

## 資金規則

完全不納入：
- 緊急預備金
- 黃金
- 其他未選擇的股票

## 更新方式
1. GitHub Desktop 分支確認為 `v5-ai-engine`
2. 解壓縮並覆蓋 `jay-invest-v2`
3. Summary：`Jay Invest V6.2 Generic Balance Strategy`
4. Commit
5. Push origin
6. 開啟 Vercel Preview

本版不需要新增 Supabase SQL。


## V6.2.1 — 財富目標總資產修正

V6.2 在整合通用平衡策略時，使用了較早版本的財富目標程式，
導致總資產欄位再次讀成不存在的 `computed.totalAssets`。

本版已修正為資產引擎實際使用的：

`computed.totalAsset`

並加入 `currentTotalAsset` 安全數值，避免資料載入期間出現：
- 目前總資產 $0
- 完成率 NaN%
- 每月所需投入 $0

V6.2 的通用平衡策略功能完整保留。
