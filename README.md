# Jay Invest V5 Alpha 3.3 — Cash Engine

## 本版完成
### 交易引擎
- 買進
- 賣出
- 現金收入
- 現金支出

### 自動連動
買進後會自動：
- 扣除投資現金
- 加入庫存
- 重算平均成本
- 建立交易紀錄
- 建立現金流水

賣出後會自動：
- 加回投資現金
- 扣除手續費
- 扣除證券交易稅
- 減少庫存
- 計算已實現損益
- 建立現金流水

### 資金管理
- 現金餘額
- 保留現金
- 可投資現金
- 交易後可投資現金預估
- 股票資金使用率
- AI 資金提醒

### 交易復原
按「復原交易」後會自動：
- 回復現金
- 回復庫存
- 重算均價
- 移除交易
- 留下復原流水紀錄

### 績效分析
- 累積已實現損益
- 賣出交易勝率
- 股票資金使用率
- 可投資現金

## 重要提醒
此版本會從交易紀錄重新計算庫存。
若你先前是直接手動建立持股、但沒有相對應的交易紀錄，第一次新增或復原交易時，舊庫存可能無法完整回推。

建議正式使用前：
1. 保留目前資料備份
2. 對現有持股補登一筆「歷史買進」
3. 再開始使用新的 Cash Engine
