# Jay Invest v3.1

這是可直接部署到 Vercel 的核心資產版。

## 新增功能
- 多檔台股持股：新增、修改、刪除
- 每檔自動計算市值、今日損益、總損益、報酬率
- 黃金雙來源自動抓取
- 黃金抓取失敗時自動使用手動備援價，不再阻斷整個頁面
- 加權指數 -10%、-20%、-30% 加碼提醒
- 可標記「已執行」，避免重複提醒
- 自動保存每日資產快照，保留 365 天
- 現金、預備金、黃金與資產目標可自行修改

## 更新既有 GitHub 專案
將壓縮包內下列項目覆蓋到 Repository 根目錄：
- app
- package.json
- README.md

Commit 後 Vercel 會自動重新部署。

## 黃金備援
如果首頁顯示黃金改用手動備援：
1. 展開「其他設定」
2. 在「黃金手動備援價（每兩）」輸入銀樓或臺銀的一兩買進價
3. 網站立即依該價格計算市值
